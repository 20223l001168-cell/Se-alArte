SeñalARTE

Aplicación Interactiva de Lengua de Señas Mexicana (LSM)

Descripción del proyecto

SeñalARTE es una aplicación móvil interactiva enfocada en facilitar el aprendizaje de la Lengua de Señas Mexicana (LSM), mediante recursos visuales, modelos tridimensionales y actividades educativas.

Objetivo

Desarrollar una herramienta tecnológica que permita a los usuarios aprender y practicar los fundamentos de la Lengua de Señas Mexicana de una manera accesible e interactiva.

Contenido educativo

La aplicación contempla las siguientes categorías:

* Alfabeto.
* Números.
* Saludos básicos.
* Colores.

Tecnologías utilizadas

* Unity Hub: desarrollo de la aplicación y entorno interactivo.
* Visual Studio Code: programación y edición de scripts.
* Modelado y animación 3D: representación visual de las señas.

Características principales

* Representación de señas mediante manos tridimensionales.
* Animaciones para facilitar la comprensión de los movimientos.
* Lecciones interactivas.
* Actividades para practicar los conocimientos adquiridos.

Público objetivo

Personas a partir de los 6 años interesadas en aprender Lengua de Señas Mexicana.
